# 🅿️ Estacionamento Inteligente (Estacionamento Smart)

Sistema web desenvolvido com foco em Orientação a Objetos (OO) para gerenciamento de um estacionamento inteligente, permitindo o controle de vagas, entrada e saída de veículos de forma dinâmica e automatizada.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web modernas:

* **HTML5** (11.5%) - Estruturação semântica das páginas.
* **CSS60.2%** - Estilização responsiva, design moderno e intuitivo.
* **JavaScript** (28.3%) - Lógica de programação orientada a objetos, manipulação do DOM e controle de fluxo do estacionamento.

## 📁 Estrutura do Projeto

* `Índice.html` - Página principal da interface do sistema.
* `script.js` - Arquivo contendo a lógica em JavaScript (orientação a objetos, regras de negócio e manipulação do DOM).
* `estilo.css` - Folha de estilos para o layout do sistema.
* `imagem/` - Pasta com recursos visuais e imagens utilizadas na aplicação.

## 💡 Funcionalidades

* Controle e status de vagas em tempo real.
* Simulação de entrada e saída de veículos.
* Aplicação de conceitos de Programação Orientada a Objetos (OO) no JavaScript.
* Interface interativa e responsiva.
